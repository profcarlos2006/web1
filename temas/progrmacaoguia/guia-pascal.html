📚 Guia Essencial: Linguagem de Programação Pascal

Pascal é fundamental para aprender **programação estruturada**. Este guia detalhado aborda desde a sintaxe básica até às estruturas de controlo e subprogramas, essenciais para o desenvolvimento de código robusto.

1. Estrutura Básica e Secções de Declaração

A ordem das secções de declaração é obrigatória em Pascal.

PROGRAM NomeDoPrograma; 
USES Crt; (* Opcional: Para usar comandos de consola *)

LABEL (* Para saltos, raramente usado em código moderno *)
CONST (* Valores fixos: Pi = 3.14159; *)
TYPE  (* Tipos de dados personalizados, ex: Arrays *)
VAR   (* Declaração de todas as variáveis usadas *)
    
PROCEDURE/FUNCTION (* Subprogramas definidos pelo utilizador *)

BEGIN (* Início do bloco de instruções principal *)
    (* Código principal aqui *)
END. (* Fim obrigatório com ponto final *)

Comentários

Use parêntesis e asteriscos (* ... *) ou chavetas { ... } para comentários. Em Free Pascal, // também é permitido.

2. Tipos de Dados e Declaração de Variáveis

A declaração de variáveis ocorre na secção **`VAR`** e segue a sintaxe: NomeDaVariavel: Tipo;

Tipo Descrição Exemplo de Declaração
**Integer** Números inteiros. `i: Integer;`
**Real** Números de ponto flutuante (decimais). `preco: Real;`
**Char** Um único caractere, entre plicas. `inicial: Char;`
**String** Texto. `sobrenome: String;`
**Boolean** Valores lógicos (`True` ou `False`). `is_valid: Boolean;`

3. Input/Output (I/O) e Atribuição

Atribuição de Valor (`:=`)

O operador de atribuição em Pascal é **`:=`** (dois pontos seguido de igual). O sinal de igual **`=`** é usado apenas para comparação.

x := 10; (* Atribui o valor 10 à variável x *)
nome := 'João'; (* Atribui a string 'João' *)

Comandos de Leitura e Escrita

Comando Função Exemplo de Uso
**`Write`** Escreve texto ou valor, **sem** saltar de linha. `Write('Nome: ');`
**`WriteLn`** Escreve texto ou valor e **salta** para a linha seguinte. `WriteLn('Resultado: ', valor);`
**`ReadLn`** Lê um valor do teclado e atribui-o à variável. `ReadLn(idade);`

5. Estruturas de Controlo de Fluxo

5.1. Condição Múltipla: CASE OF

Estrutura eficiente para substituir várias instruções IF-THEN-ELSE IF, baseada no valor de uma expressão.

CASE opcao OF
    1: WriteLn('Escolheu Opção 1');
    2, 3: WriteLn('Escolheu 2 ou 3'); (* Múltiplos valores *)
    'S': WriteLn('Sim');
    ELSE
        WriteLn('Opção inválida.');
END; (* Deve ser terminado com END; *)

5.2. Ciclo Repetição Controlada: FOR-DO

Usado quando o número de iterações é conhecido. A variável de ciclo (i) deve ser `Integer` ou `Char`.

(* Contagem crescente: de 1 até 10 *)
FOR i := 1 TO 10 DO
    WriteLn(i); 

(* Contagem decrescente: de 10 até 1 *)
FOR j := 10 DOWNTO 1 DO
BEGIN
    WriteLn(j);
END;

5.3. Ciclos Condicionais (WHILE e REPEAT)

Para iterações onde o número de repetições não é fixo.

(* WHILE-DO: Condição testada ANTES. Pode não executar nenhuma vez. *)
WHILE (i < 10) DO
BEGIN
    i := i + 1;
END; 

(* REPEAT-UNTIL: Condição testada DEPOIS. Executa PELO MENOS uma vez. *)
REPEAT
    i := i + 1;
UNTIL (i = 10);

6. Funções e Procedimentos (Subprogramas)

Subprogramas promovem a modularidade e reutilização de código.

Procedimento (Não Retorna Valor)

PROCEDURE MostrarMensagem(texto: String);
BEGIN
    WriteLn('==> ', texto, ' <==');
END;

BEGIN
    MostrarMensagem('Isto é um procedimento.');
END.

Função (Retorna um Valor)

A Função deve retornar um valor do tipo especificado no cabeçalho. O resultado é atribuído ao nome da própria função.

FUNCTION Somar(a, b: Integer): Integer;
BEGIN
    Somar := a + b; (* O nome da função recebe o valor de retorno *)
END;

VAR
    resultado: Integer;
BEGIN
    resultado := Somar(5, 7);
    WriteLn('A soma é: ', resultado);
END.

7. Estruturas de Dados: Arrays (Vetores)

Um **Array** é uma coleção de itens do mesmo tipo de dados, armazenados em posições contíguas e acessíveis através de um índice.

Declaração e Uso

VAR
    notas: ARRAY[1..5] OF Real; (* Array com 5 posições, de índice 1 a 5 *)
    nomes: ARRAY[0..99] OF String; (* Array com 100 posições, de 0 a 99 *)
    
BEGIN
    (* Atribuir valores a posições específicas *)
    notas[1] := 18.5;
    notas[5] := 10.0;
    
    (* Aceder ao valor *)
    WriteLn('A primeira nota é: ', notas[1]:0:1);
    
    (* Usar um ciclo para percorrer o Array *)
    FOR i := 1 TO 5 DO
        WriteLn('Nota ', i, ': ', notas[i]:0:1);
END.
