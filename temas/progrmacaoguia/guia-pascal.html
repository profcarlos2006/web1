🖥️ Introdução à Linguagem Pascal

Pascal é uma linguagem de programação estruturada, desenvolvida por Niklaus Wirth no final dos anos 60. É valorizada pela sua clareza, sintaxe rigorosa e por ser excelente para o ensino de conceitos de programação.

1. Estrutura Básica de um Programa Pascal

Um programa Pascal é definido pela palavra-chave PROGRAM e é sempre delimitado por BEGIN e END.

PROGRAM OlaMundo;

BEGIN
    (* Comando para escrever na consola *)
    WriteLn('Olá Mundo em Pascal!');
    
    (* O ponto final no último END termina o programa *)
END.

Declaração de Variáveis

Em Pascal, todas as variáveis devem ser declaradas antes de serem usadas, na secção VAR.

PROGRAM ExemploVar;
VAR
    idade: Integer;
    nome: String;
    salario: Real;

BEGIN
    (* O corpo do programa vai aqui *)
END.
---

2. Principais Tipos de Dados

A tipagem forte de Pascal exige que o programador defina o tipo de informação que cada variável irá conter.

Tipo Descrição Exemplo
**Integer** Números inteiros (sem casas decimais). 150, -42
**Real** Números de ponto flutuante (com casas decimais). 3.14159, 25.5
**Char** Um único caractere alfanumérico. 'A', '9'
**String** Sequência de caracteres. 'Portugal'
**Boolean** Valores lógicos (Verdadeiro ou Falso). True, False
---

3. Estruturas de Controlo de Fluxo

As estruturas de controlo de fluxo permitem tomar decisões e executar blocos de código repetidamente.

3.1. Condição: IF-THEN-ELSE

Executa um bloco de código se uma condição for verdadeira.

IF (idade >= 18) THEN
    WriteLn('Maior de idade')
ELSE
    WriteLn('Menor de idade');

3.2. Ciclo: FOR-DO

Repete uma ação um número predefinido de vezes.

FOR i := 1 TO 5 DO
BEGIN
    WriteLn('Contagem: ', i);
END;

3.3. Ciclo: WHILE-DO

Repete uma ação enquanto uma condição for verdadeira.

WHILE (contador < 10) DO
BEGIN
    WriteLn(contador);
    contador := contador + 1;
END;
---

4. Funções e Procedimentos

Em Pascal, blocos de código reutilizáveis são chamados de **Procedimentos** (não retornam valor) ou **Funções** (retornam um valor).

Exemplo de Procedimento

PROCEDURE Saudacao(nome: String);
BEGIN
    WriteLn('Olá, ', nome, '!');
END;

BEGIN
    Saudacao('Ana'); 
END.
