🐧 O Sistema Operativo Linux

O Linux é um kernel de sistema operativo de código aberto, usado em todo o mundo, desde dispositivos Android até aos maiores supercomputadores e quase todos os servidores web.

Fundamentos Essenciais

  • **Distribuições (*Distros*):** Diferentes versões do Linux (ex: Ubuntu, Debian, Fedora, CentOS).
  • **Terminal:** A interface de linha de comandos (CLI) é a forma mais poderosa de interagir com o sistema. Comandos como `ls`, `cd`, `grep` e `ssh` são a base.
  • **Sistema de Ficheiros:** A organização hierárquica dos ficheiros, com `/`, `/home`, `/etc` e `/var`.

Porquê é Crucial?

No desenvolvimento de software e infraestruturas, o Linux é dominante devido à sua **estabilidade**, **segurança** e **flexibilidade**. É o sistema operativo *default* para *Docker* e *Cloud Computing*.

Comandos de Exemplo

            
# Ver informações sobre o sistema
uname -a

# Gerir pacotes (exemplo Debian/Ubuntu)
sudo apt update
sudo apt install NOME_DO_PACOTE

# Listar ficheiros em modo detalhado
ls -lah
