🔗 Git e GitHub: Controlo de Versão

O **Git** é o sistema de controlo de versões distribuído mais usado no mundo. O **GitHub** é a plataforma de alojamento baseada em Git que permite a colaboração global.

Git: O Histórico do Código

O Git permite-lhe **rastrear alterações** nos ficheiros, **reverter erros** e gerir diferentes fluxos de trabalho através de *branches* (ramos). É o pilar da **colaboração** e da segurança de código em equipa.

GitHub: A Plataforma Social

GitHub oferece uma interface web para os repositórios Git, facilitando a gestão de projetos, a revisão de código (*Pull Requests*) e o acompanhamento de problemas (*Issues*). É essencial para o *open-source*.

Terminologia Essencial

  • **Commit:** Uma consolidação que guarda uma alteração no histórico.
  • **Branch:** Um ramo de trabalho independente do código principal.
  • **Merge:** O ato de unir alterações de um ramo noutro.
  • **Clone:** Criar uma cópia local de um repositório remoto.
