☁️ Cloud Computing (AWS/Azure)

O *Cloud Computing* é a entrega de serviços de computação (servidores, armazenamento, bases de dados, software) pela Internet, permitindo o acesso *on-demand* a recursos partilhados.

Modelos de Serviço

  • **IaaS (Infrastructure as a Service):** Aluguer de hardware básico (máquinas virtuais, armazenamento). Ex: EC2 na AWS.
  • **PaaS (Platform as a Service):** Oferece um ambiente completo para desenvolvimento e implantação de aplicações. Ex: App Service no Azure.
  • **SaaS (Software as a Service):** Software pronto a usar entregue pela web. Ex: Google Workspace, Microsoft 365.

Vantagens

As principais vantagens são a **escalabilidade** (aumentar ou diminuir recursos instantaneamente), a **redução de custos** (pagar apenas pelo que se usa) e a **alta disponibilidade**.

Provedores Chave

Os maiores provedores de serviços *cloud* são a **Amazon Web Services (AWS)**, **Microsoft Azure** e **Google Cloud Platform (GCP)**.
