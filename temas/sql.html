🗃️ SQL: Linguagem de Consulta Estruturada

SQL é a linguagem padrão usada para gerir e manipular **bases de dados relacionais**. É essencial para qualquer aplicação que precise de armazenar dados de forma estruturada.

Estrutura Relacional

As bases de dados relacionais organizam os dados em **tabelas**, onde cada tabela é composta por **linhas** (registos) e **colunas** (atributos). As relações entre tabelas são definidas por **chaves**.

Os Quatro Comandos Essenciais (CRUD)

  • **CREATE (Criar):** `INSERT INTO` (inserir novos dados)
  • **READ (Ler):** `SELECT` (o comando mais usado, para recuperar dados)
  • **UPDATE (Atualizar):** `UPDATE` (modificar dados existentes)
  • **DELETE (Apagar):** `DELETE FROM` (remover registos)

Vantagens

Bases de dados SQL garantem a **integridade dos dados** através de regras de consistência e são ideais para dados com relações complexas e que exigem transações seguras (propriedade **ACID**).
