Partilhar a Sua Imagem Docker

Para partilhar a sua imagem Docker com outros utilizadores, deve seguir o processo de **construção e envio** (push) para um repositório público como o **Docker Hub**.

Passo 1: Ficheiro de Construção (Dockerfile)

Garantir que tem um **Dockerfile** que define como a sua imagem será construída:

# Usa uma imagem base leve do Nginx
FROM nginx:alpine

# Copia o seu ficheiro HTML para o contentor
COPY index.html /usr/share/nginx/html/index.html

Passo 2: Construir e "Taggar" a Imagem

Atribua um nome que inclua a sua conta do Docker Hub (Ex: `profcarlos2006/nginx-testedocker13:latest`):

docker build -t profcarlos2006/nginx-testedocker13:latest .

Explicação:

  • -t: A *flag* para "tag", que atribui o nome e a versão.
  • profcarlos2006/...: O seu nome de utilizador no Docker Hub.
  • :latest: A "tag" ou versão da imagem.
  • .: Indica que o Docker deve procurar o **Dockerfile** no diretório atual.

Passo 3: Enviar a Imagem para o Docker Hub

Faça o login e envie a imagem construída para o repositório público:

docker login
# Insira o seu nome de utilizador e password
docker push profcarlos2006/nginx-testedocker13:latest

Como Outros Utilizadores Podem Usar:

Qualquer pessoa pode descarregá-la e usá-la com:

docker run -p 8080:80 profcarlos2006/nginx-testedocker13:latest
