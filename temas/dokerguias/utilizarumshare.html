Guia Rápido: Executar o Projeto Docker Partilhado

Este guia explica como iniciar um contentor usando uma imagem pré-construída (`profcarlos2006/nginx-testedocker13`) e garantir que pode editar os ficheiros localmente usando **Volumes**.

1. Estrutura de Ficheiros

Na sua pasta de projeto, crie a seguinte estrutura:

  • docker-compose.yml (O ficheiro de configuração)
  • **Pasta site/** (Onde guardará o seu index.html de desenvolvimento)

2. Conteúdo do docker-compose.yml

Guarde o código abaixo no ficheiro **docker-compose.yml**. Ele irá puxar a imagem do Docker Hub e montar a sua pasta local.

version: '3.8'

services:
  web:
    # A imagem partilhada no Docker Hub
    image: profcarlos2006/nginx-testedocker13:latest
    container_name: nginx-carlos-teste

    # Mapeamento de portas (8080 local -> 80 do contentor)
    ports:
      - "8080:80"

    # O VOLUME (Bind Mount): Liga a sua pasta "site" ao servidor web do contentor
    volumes:
      - ./site:/usr/share/nginx/html

    restart: always

3. Execução e Acesso

No terminal (na mesma pasta onde está o docker-compose.yml), execute o seguinte comando:

Comando de Arranque

docker compose up -d

Nota: Como a imagem já está construída, o Docker irá simplesmente puxá-la e iniciar o contentor.

⚠ Como Aceder à Aplicação

Aceda ao servidor web através do seu navegador em: **http://localhost:8080/**

Qualquer alteração na sua pasta **site** será refletida imediatamente ao recarregar a página.

4. Comandos de Manutenção

Quando terminar, use o comando para parar e remover o contentor:

docker compose down
