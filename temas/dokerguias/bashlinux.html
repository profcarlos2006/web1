Guia de Aprendizagem Linux com Docker

Este ambiente de exercícios usa o Docker para lhe dar acesso a um **terminal Linux puro** sem alterar nada no seu computador. Perfeito para aprender!

1. Aceder ao Terminal Interativo (BASH)

Execute o seguinte comando no seu terminal. Ele vai descarregar a imagem base **Ubuntu**, criar um contentor e entrar imediatamente no *shell* interativo.

docker run -it --rm ubuntu bash

O Significado do Comando:

  • -i (interactive): Mantém o STDIN aberto.
  • -t (tty): Atribui um pseudo-terminal para interagir com a linha de comandos.
  • --rm: Remove automaticamente o contentor quando sair (Ideal para exercícios).
  • ubuntu: A imagem base do sistema operativo Linux.

2. Ligar uma Pasta Local para Exercícios (-v)

Se precisar que os ficheiros criados no contentor permaneçam no seu PC, utilize o argumento **-v** (Volume).

docker run -it --rm -v "$(pwd)/exercicios:/app" ubuntu bash

Nota: No Windows, o `$(pwd)` deve ser substituído pelo caminho completo da sua pasta.

O que faz o -v "$(pwd)/exercicios:/app"?

  • **`$(pwd)/exercicios`:** O caminho da pasta local no seu PC.
  • **`/app`:** O caminho dentro do contentor onde os seus ficheiros estarão disponíveis.

Lembre-se de usar **`cd /app`** depois de entrar no terminal.

3. Exercícios Práticos de Comandos Linux

Entre no seu contentor e comece a praticar!

Exercício 1: Navegação e Visualização

  1. Qual o comando para saber em que diretório (pasta) se encontra?
  2. Liste todos os ficheiros (incluindo os ocultos) do diretório raiz (`/`).

Comandos:

# 1. Onde estou:
pwd 

# 2. Listar ficheiros (incluindo ocultos):
ls -la /

Exercício 2: Criar e Mudar

  1. Crie um diretório chamado `documentos`.
  2. Dentro de `documentos`, crie um subdiretório chamado `trabalho`.
  3. Mude para o diretório `trabalho`.
  4. Volte ao diretório anterior.

Comandos:

# 1. Criar o diretório:
mkdir documentos

# 2. Criar subdiretório:
mkdir documentos/trabalho 

# 3. Mudar para o diretório trabalho:
cd documentos/trabalho

# 4. Voltar ao diretório anterior:
cd ..

Exercício 3: Ficheiros e Conteúdo

  1. Crie um ficheiro vazio chamado `nota.txt`.
  2. Use um comando para adicionar o texto "Hello World" a esse ficheiro.
  3. Visualize o conteúdo completo do ficheiro na tela.

Comandos:

# 1. Criar ficheiro vazio:
touch nota.txt

# 2. Adicionar texto:
echo "Hello World" > nota.txt

# 3. Visualizar conteúdo:
cat nota.txt

4. Dica: Sair do Contentor

Para fechar o terminal e parar o contentor, basta digitar **`exit`**.

O contentor será removido automaticamente graças ao `–-rm`.
